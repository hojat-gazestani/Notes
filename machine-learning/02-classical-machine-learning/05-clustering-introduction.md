# CLUSTERING

Identify clusters of data that share similar attributes.

+ segment of customers that purchase at the same time to discern what factors influence their purchasing behavior.
+ By understanding a particular cluster of customers, which products to recommend to customer groups through promotions
and personalized offers.

+ pattern recognition
+ fraud detection
+ image processing

## supervised learning
clustering is used to classify new data points into existing clusters through **k-nearest neighbors (k-NN)**

## unsupervised learning
clustering is applied to identify discrete groups of data points through **k-means** clustering.
