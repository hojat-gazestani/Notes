# Logistic Regression

+ “A” or “B?” 
+ “positive” or “negative?”
+ “potential customer” or “not a potential customer?”

**Linear regression:** addresses numerical equations and forms numerical predictions to discern relationships between variables,

**Logistic regression:** adopts the sigmoid function to analyze data and predict discrete classes that exist in a dataset.  shares a visual resemblance to linear regression, 
+  predicts discrete classes.
+ used for binary classification to predict two discrete classes

+ data should be free of missing values 
+ all variables are independent of each other. 

![logistic](https://github.com/hojat-gazestani/Notes/blob/main/machine-learning/01-foundations/pics/08-Logistic-Regression/Figure-6%3A-An-example-of-logistic-regression.png)

**Use case**

+ fraud detection,
+ disease diagnosis,
+ emergency detection,
+ loan default detection,
+  identify spam email through the process of identifying specific classes, e.g. non-spam and spam. 

**sigmoid function:**  produces an S-shaped curve that can convert any number and map it into a numerical value between 0 and 1
+  convert numerical results into an expression of probability between 0 and 1
